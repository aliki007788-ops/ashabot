# __TITLE__ — بسته‌ی آماده‌ی اجرا

نسخه‌ی میزکار __VERSION__ · کیت __KIT__

## این بسته چیست؟
یک برنامه‌ی کامل Next.js که فقط همین میزکار را نمایش می‌دهد: نقشه‌ی زنده‌ی فرایند، پرونده‌ها، هدف و برنامه‌ی هوشمند، ربات‌ها و دستیار.

## نیازمندی مهم
میزکار برای کار کردن به **API پلتفرم آشا** وصل می‌شود (ربات‌ها، هوش مصنوعی و ذخیره‌ی پرونده‌ها آنجا هستند). پس:
- آدرس API و یک حساب کاربری فعال از فروشنده بگیرید.
- آدرس را در فایل `.env.local` بنویسید (نمونه: `.env.example`).

## راه‌اندازی (۴ دستور)
```
npm install
copy .env.example .env.local      (در مک/لینوکس: cp)
npm run dev
```
بعد http://localhost:3000 را باز کنید و با حساب خود وارد شوید.

## انتشار روی اینترنت
پوشه را روی Vercel (یا هر میزبان Next.js) بارگذاری کنید و متغیر `NEXT_PUBLIC_API_URL` را بگذارید.

## نکته
پوشه‌ی `src/workspaces/__SLUG__/_kit` را دستی ویرایش نکنید؛ به‌روزرسانی‌ها فقط با جایگزینی کل آن پوشه انجام می‌شود.
